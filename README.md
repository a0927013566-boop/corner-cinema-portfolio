# 角落電影院｜作品集

正式網站：[角落電影院作品集](https://a0927013566-boop.github.io/corner-cinema-portfolio/)。訪客不需登入；網站內容由本倉庫的 `main` 分支發布。

這是一個可攜式的靜態作品集網站，使用標準 HTML、CSS、JavaScript，不依賴任何 AI 平台、資料庫、套件或建置服務。`index.html` 是內容、`style.css` 是外觀；不需要後台即可閱讀。使用瀏覽器開啟 `index.html` 即可預覽。

## 其他 AI 如何接手

1. 讀取本 README、`HANDOFF.md`，再讀程式碼及 Git 最新 main；保留使用者的新指示與並行工作。
2. 更新文字與作品資料時編輯 `index.html`；修改版型看 `style.css`。作品和外部連結應依本人最新授權與實際可用性更新。
3. 在桌面與窄螢幕測試導覽、連結、文字和畫面；不要把未執行的測試說成通過。
4. 以有權限的 GitHub 身分提交變更，經約定的審查與合併流程更新網站；公開訪客沒有網站編輯功能。任何 AI 都必須由本人授權並取得倉庫寫入權限。
5. 不要提交私人資料、存取權杖或家人／客戶素材；公開倉庫的所有內容與 Git 歷史都可被複製。媒體與公開連結依本人授權處理。

## 部署

目前使用 GitHub Pages，發布來源為 `main` 分支根目錄。變更合併到 `main` 後，GitHub 自動發布；應確認 `pages build and deployment` 成功，再讀回正式網址。第一次發布於 2026-11-07（台北時間）成功。

全部網站檔案位於倉庫根目錄，無套件安裝或自訂建置步驟，也可移至其他靜態託管平台。後續維護以本倉庫為準，私人主倉中的網站快照不會自動同步。
