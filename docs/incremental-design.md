## 第一步：頁首（改碼前鎖定）

- 問題：原來深色品牌帶被改成紙白，與夜景主視覺的連續感被削弱。
- 保留：純文字品牌、目前字級、導覽／目錄連結、手機可點範圍、桌面置頂行為；不恢復 C·C。
- 改動：只調整 `.header` 內背景、前景、邊線、懸停及鍵盤焦點色；不改尺寸。**其他區塊不動。** 導覽實測發現既有 sticky 頁首作為 `#top` 錨點無法可靠回頁頂，因此將同一 id 移至 body；不改既有網址與連結，頁尾回頂也沿用此修正。
- 外觀驗收：原版／修改前／修改後相同桌面及手機寬度，首屏與全頁實看；非頁首區域像素應相同。
- 功能驗收：導覽與目錄可到達、鍵盤可辨識焦點、320／390／768／1440px 無橫向溢位。影音程式及資料無 diff；不因色彩改動重跑全部媒體。
- 結果：桌面／手機實看完成；1440px 變動像素只在頂端 94px，390px 只在頂端 135px，其他全頁像素一致。320／390／768／1440px 導覽、回頁頂、鍵盤焦點與可點高度通過；桌面目錄可開。修正前 768／1440px 回首頁仍停於 scrollY 5034／4371，移動錨點後均回 0。程式及資料未改。這是自查結果，尚未取得本人視覺採用回饋，部署另記。

後續順序：先完成及展示這一步，再分別對照主視覺、作品區。音樂、播放、作品數量與公開排除項均須保持。不得把這份計畫當完成結果。

## 第二步：主視覺（改碼前鎖定）

第一步已提交並合併 PR #7，頁首比較圖已向本人展示；不代表本人已採用。這一步只改 `.hero` 及其內部排版。其他區塊不動。

- 原版有完整夜景畫幅，前版縮短為桌面約652px／手機520px，並加入頁首下白縫，降低連續感。
- 恢復無白縫的夜景入口，桌面680–780px、手機至少620px；內容上緣稍放鬆。保留目前清楚的文字、作品圖、中文導讀、播放入口及底部作品標示，不換成別人的 showreel 或自動播放。
- 來源取捨：Ligthelm 作品頁讓主要影像佔大畫幅；本站採用原站已有的夜景構圖，不照搬黑底全站或其姓名字標。實點 MORE INFO 已看到片說／攝製資訊與劇照，說明深度內容應有實際素材支撐，不能僅用裝飾標題充數。
- 另實點 DiFelice 手機 MENU，顯示四項導覽，內容往下移；本站只有三項主要導覽，保留直接可見連結，毋須為模仿而藏入選單。
- 驗收：桌面／手機前後實看、320px無斷裂或互疊、影片能開啟／播放／定位／關閉；其他區塊相對尺寸與內容保持。
- 結果：1440／768px 夜景780px、390／320px為620px；頁首下白縫為0。按鈕與底部片名不互疊；其他五個區塊的寬高與上一版本完全一致。390／1440px實際播放、定位120秒、關閉及焦點返回通過。桌面與手機截圖已實看；仍屬自查，發布另記。

## 第三步：MV 展示（改碼前鎖定）

第二步已合併 PR #8，主視覺結果已展示。這一步只改作品區內兩支 MV 的呈現，其他區塊不動。

- 原版兩支 MV 並排比較，前版改成圖文交錯的長列。恢復桌面並排，手機單欄；保留分類、片名、片長、原作品封面、文字說明與直接播放，不刪內容來縮頁。
- 補充真正內容：每支三張成片影格，展現畫面／光線的進展；另用原生 details 展開創作筆記，鍵盤與無 JS 都可使用。不把資料塞進只能懸停的控件，不新增自動播放。
- 內容來源：本人既有公開成片；《越過長夜》製作紀錄確認從夜行到日出、28鏡、中英字幕；《路燈亮起的時候》原故事確認舊友重逢與各自離開、Suno男女對唱。只整理可展示的作品故事與做法，不公開私人來源網址、檔案路徑或原始提示詞。
- 參考原理：DiFelice 的密集作品影像用於恢復可比較的大圖；Ligthelm 作品頁的影片／片說／劇照層次用於新增有根據的筆記與影格。本站仍用自己的圖、字體、品牌與暖色，不抄版型。
- 驗收：原版及前版對照；桌面／手機完整區塊、縮圖裁切與筆記展開；分類與兩支 MV 播放；靜態和動態卡相同；其他作品、音樂及頁首／主視覺保持。
- 結果：1440／390px與320px筆記已實看；320／390／768／1440px無橫向溢位、鍵盤展開與全部分類通過。390／1440px兩MV播放、90秒定位、關閉返回焦點及音影互斥通過。無JS與JSON503時筆記、影格及7組作品仍可用。新增 notes 以外的作品資料、作品區以外HTML完全相同。6張影格已逐張實看，排除轉場疊影；來源時間見證據manifest。這是本輪自查，未冒稱本人採用。
