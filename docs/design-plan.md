## 最終行為

- 作品資料維持 JSON。靜態 HTML 預先有 7 組作品和 7 首歌曲；JS 增強篩選、搜尋與站內播放。模組或資料請求失敗時保留直連，完整目錄有全部 19 集、5 支影片和 41 首音樂。
- 主內文 16px、導覽 16px、曲目次資訊 14px；主要播放／篩選／關閉按鈕至少 44px 高。裝飾英文字與標誌輔助字有較小尺寸，並非所有字都至少 14px。不引入外部字型、3D 或強制捲動。
- 音樂播放不遮住頁面。按一首時預設不接續；「播放這份清單」會啟用接續。佇列是開始播放當下的篩選快照，後續搜尋不會偷偷改下一首。最後一首播完就停。
- 320px 窄螢幕的原生音樂控制會縮短時間軸，因此另提供有標籤的完整進度滑桿，支援鍵盤與觸控；桌面仍用原生控制。
- 開影片會停止並卸載音樂；關閉影片卸載媒體、恢復焦點。直接深連結預設不自動發聲；按作品後可以用返回鍵關閉，前進重新開啟但不自動播放。
- 分享提供完整網址；剪貼簿受限時選取輸入框供手動複製，不要求訪客帳號。
- 未開始播放不請求影音或 YouTube。主圖優先載入，其他圖片 lazy-load；無 JavaScript 也看得到作品。
