# 角落電影院：質感與細節（2026-11-07 本人要求）

## 本人要求與界線

本人要求研究頂尖專業網頁設計（只學概念、不抄），以私人 ai-director 倉庫技能、Drive 副業的 GPT 通用提示詞模組與 SOP 禁止項 R01～R16 為依據，在既有網站上優化「美觀、排版、質感、細節，還有看得出設計感的特效」，持續到完成並每階段合併。原首頁圖片與構圖、7組／19集／5影片／41曲、單一聲源、全部播放與備援、排除項與 C·C 停用全部保留；已否決的刊物版、金色板片不回來。這一輪的自查與測試不等於本人採用。

## 研究：本輪實際打開的案例

- **Adam Bricker**（Awwwards 2026 Site of the Day，攝影指導作品集）：以受控瀏覽器實際進站並向下捲動四屏。作品滿版、介面全部退到角落；角落資訊用攝影機觀景窗語言（時間碼、影格率、畫幅比例、對焦框），作品索引有刻度尺。學到：**作品是主角，介面細節用「拍片現場」的語言，但必須精準而少**。本站轉化：用自己真實的片長、集數、類別做場記式數字與對焦框；不搬它的字、版面、數值或程式。
- **Obys**（Awwwards 得獎設計工作室）：實際進站捲動。字級層次極強、作品索引清單、括號框聚焦、即時小資訊。學到：**細節靠一致的規則，不靠數量**。不搬黑白極簡風格與括號造型。
- 前輪已實看 Siena Film Foundation、Lusion、David Whyte Experience（見 cinematic-direction.md），延續「夜間放映室」主張。
- 技術原理（公開文件與實作經驗）：捲動帶動的動畫只動位移、透明度與裁切最順；「快門／遮罩」揭開比淡入更有電影感；極淡的底片顆粒讓平塗色塊有材質並減少色帶；全部動態都要能被減少動態關掉。

## 基線問題（1440／390 全頁實看 main 1cb7eb5）

1. 奶白與墨綠是完全平塗的色塊，缺少材質。
2. 片長、集數、編號、時間碼各用不同字樣，沒有統一的細節語言。
3. 作品卡進場只有淡入上浮與小幅傾斜，沒有「放映」的語感；懸停只有放大 2.5%。
4. 段落標題直接出現；奶白段落與深色音樂段之間是硬切。
5. 音樂清單是一格一格的框線卡，制式感重。
6. 頁首是一條平的深色帶，與首屏關係弱。

## 階段

- **S1 質感底層**：全站極淡靜態底片顆粒；時間碼、片長、集數、編號改用場記式等寬數字。
- S2 作品卡：放映快門揭幕＋觀景窗對焦。
- S3 段落標題遮罩上升＋深淺段落「燈光漸暗」過渡。
- S4 音樂清單去框精修與播放中狀態。
- S5 頁首與頁尾細節。

## S1 自查

顆粒在深色段可見細微銀粒，奶白段只有紙感，不遮作品；播放器開啟時隱藏。第一版讓顆粒每秒八格跳動，受控瀏覽器（軟體繪圖）下放映廊幀率明顯下降、自動巡映測試逾時，改為靜態顆粒後四組測試全通過。中文計數字串不套等寬字，避免中文變小。
