# 方框 C·C 圖標查核

查核對象是網站最初由 AI 排出的「同向雙 C＋中間圓點＋細方框」，不是品牌名稱。

2026-11-07（台北時間）已將實際圖樣送入[智慧財產局商標檢索系統](https://cloud.tipo.gov.tw/S282/S282WV1/)「以圖找圖」，取得 984 個演算法候選；其中第 41 類篩出 46 個候選。候選數不是法律近似或侵權件數。已保存首 20 筆及第 41 類三頁結果供圖樣比較，正補看實際圖片與 C·C／CC 字樣結果。

網站先撤下此新圖標，使用既有品牌純文字呈現。這是處理未確認標誌的設計決定，不代表已認定原圖侵權，也不代表純文字品牌已完成商標清查。

圖形檢索是初步篩查；官方明示以圖找圖仍為 beta 輔助，另須用圖形路徑檢索、商品／服務與權利狀態判斷。不得用「AI 自畫」「一般搜尋沒找到相同圖」保證安全。後續查核結果另補；沒有代送商標申請。

這是查核方向，不是正式法律意見；重大事項請找律師或主管機關。
