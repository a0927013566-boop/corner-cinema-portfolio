## 第一步：頁首（改碼前鎖定）

- 問題：原來深色品牌帶被改成紙白，與夜景主視覺的連續感被削弱。
- 保留：純文字品牌、目前字級、導覽／目錄連結、手機可點範圍、桌面置頂行為；不恢復 C·C。
- 改動：只調整 `.header` 內背景、前景、邊線、懸停及鍵盤焦點色；不改尺寸。**其他區塊不動。** 導覽實測發現既有 sticky 頁首作為 `#top` 錨點無法可靠回頁頂，因此將同一 id 移至 body；不改既有網址與連結，頁尾回頂也沿用此修正。
- 外觀驗收：原版／修改前／修改後相同桌面及手機寬度，首屏與全頁實看；非頁首區域像素應相同。
- 功能驗收：導覽與目錄可到達、鍵盤可辨識焦點、320／390／768／1440px 無橫向溢位。影音程式及資料無 diff；不因色彩改動重跑全部媒體。
- 結果：桌面／手機實看完成；1440px 變動像素只在頂端 94px，390px 只在頂端 135px，其他全頁像素一致。320／390／768／1440px 導覽、回頁頂、鍵盤焦點與可點高度通過；桌面目錄可開。修正前 768／1440px 回首頁仍停於 scrollY 5034／4371，移動錨點後均回 0。程式及資料未改。這是自查結果，尚未取得本人視覺採用回饋，部署另記。

後續順序：先完成及展示這一步，再分別對照主視覺、作品區。音樂、播放、作品數量與公開排除項均須保持。不得把這份計畫當完成結果。
